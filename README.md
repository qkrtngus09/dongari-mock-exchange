# 동아리 모의주식 거래소

가상 주가, 가상 현금, 주식 매수/매도, 자산 요약, 거래 내역, SVG 주가 차트를 포함하는 기본 버전입니다.

## 파일
- `index.html`: 앱 전체 화면과 기능
- `manifest.json`: PWA 설치 설정
- `sw.js`: 기본 오프라인 캐시
- `icon.svg`: 앱 아이콘

## 컴퓨터에서 빠르게 확인
1. ZIP 압축을 풉니다.
2. `index.html`을 Chrome, Edge 또는 Firefox에서 엽니다.
3. 가상 매수/매도, `하루 진행`, 새로고침 후 데이터 유지 여부를 테스트합니다.

브라우저에서 직접 파일을 여는 방식(`file://`)에서는 PWA 설치와 서비스 워커가 작동하지 않을 수 있습니다. 웹 설치를 테스트하려면 HTTPS로 호스팅하거나 로컬 개발 서버를 사용하세요.

## 웹 배포와 안드로이드 설치
1. GitHub 계정에서 새 저장소를 만듭니다.
2. 이 폴더의 네 파일을 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 설정하고 공개 URL이 생성될 때까지 기다립니다.
4. 안드로이드 Chrome에서 HTTPS 주소를 엽니다.
5. 브라우저 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 표시되는 메뉴는 기기/브라우저에 따라 다를 수 있습니다.

## 중요한 제한
- 주가는 모두 임의로 생성되는 교육용 가상 데이터입니다.
- 데이터는 각 브라우저의 `localStorage`에 저장되며, 기기 간 동기화되지 않습니다.
- 사이트 데이터를 지우거나 브라우저를 바꾸면 저장 정보가 사라질 수 있으니 테스트용으로 사용하세요.
- 회원 공동 사용, 로그인, 랭킹, 서버 백업이 필요하면 백엔드와 데이터베이스가 추가로 필요합니다.
- PWA 설치는 APK 파일 생성과 다릅니다. APK가 필요하면 별도 패키징 단계가 필요합니다.
